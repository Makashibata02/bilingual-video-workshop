# 验证范围

## 自动化测试

- 字幕解析、重叠时间轴拒绝、未完成翻译恢复、取消与文件锁。
- 同一视频多次导出不覆盖，方案编号与布局编号可区分。
- API 请求携带选定模型；本地模拟服务中的成功和错误返回。
- Windows DPAPI 虚构密钥往返、方案切换及 GUI 测试按钮。
- 时间条拖动与精确时间输入，默认全片。
- 下载保存位置、名称、同名防覆盖、特殊字符和路径穿越拒绝。
- 窄字幕带字号、长文完整性与几何位置，PPT 模式原画面位置。
- 发布白名单、敏感路径和不回显秘密的扫描报告。

这些测试不使用真实付费密钥，不下载用户媒体。排版测试的合成字幕与幻灯片由本项目提供。

2026-10-24 的源码整理验证：从白名单源码 ZIP 解压，在新建的 Python 3.12 环境中仅安装 `requirements-test.txt`，**34 项测试全部通过**；解压后的 46 个公开文件也通过隐私规则及 Gitleaks 检查。GUI 测试使用本机 Tcl/Tk 和 Windows 字体，未使用个人配置、视频、模型或旧版应用源码。这不等于已在一台全新的 Windows 电脑验收可执行程序。

1.6.0 功能验证已增加为 **51 项离线测试**，覆盖导入不自动开始、取消确认、逐视频范围及批量设置、重试等待、校对续接、新模型导出独立目录、确认译名快照、AI 候选不自动生效、日语来源和编码、上下文编号，以及识别缓存隔离。字形测试和 GUI 检查保留其系统字体与 Tcl/Tk 边界。

本机实际打包进程另通过本地 HTTP 模拟测试：日语 API 短句、部分缓存下的上下文翻译与名称候选，共 4 个请求，使用虚构密钥，不使用真实付费接口。免费必应日语短句已实际返回译文。真实视频、字幕、处理日志和截图均保存在本地验证目录，不随公开源码分发。

1.6.0 的独立打包进程已完成官方公开动漫原视频的三分钟选段处理：本地 small 日语识别、必应日中翻译、49 条双语字幕与 MP4 导出。输出 1280×796，原画面区域保持 1280×720，窄字幕带 76 像素，音视频约 180 秒，完整音视频解码及多处画面检查通过。免费示例仍有 4 处译名核查提示，不作为 API 强约束或人工校译质量的证明；真实付费 API 尚未调用。

公开 YouTube / X 短视频的下载已做实际验证；并不保证任意链接、登录限制或未来网站版本都能下载。公开源码不附带这些媒体、字幕、截图或本地验收实录。

源码文件哈希、Python 与 PowerShell 语法已检查。基础模型的 11 个文件，以及新增 small 的 4 个文件，均在本机校验 SHA-256；small 下载使用固定官方版本。1.6.0 已重新打包并完成上述本机运行验证，原始模型的完整重新下载流程未全部重跑。本机可执行程序和模型不作为公开源码包的一部分，也不能作为干净公开构建的证明；公开二进制仍需在官方 Python 环境另行构建并审核分发许可。

真实付费服务、无中文字体机器、未经测试的 Python / 依赖组合和重新分发的二进制包仍应由使用者单独验收。

独立打包进程完成真实日语识别、两条 DSFlash 翻译及 GUI 窗口启动。复用已验证译文生成27.45秒片段，1920×1184，原始画面1920×1080不缩放、字幕带104像素；H.264 CRF16、12线程，9.50秒压制，完整音视频解码与画面检查通过。两条额外打包验证消耗743 tokens。

实际读取本机24物理核／32逻辑线程、约64GB内存和Intel UHD770；DXGI专用显存128MiB、共享内存上限约32GiB，重复适配器信息合并显示。识别4线程、压制12线程；所有受测子进程的实际优先级为 Below Normal。硬件预算不是硬性占用百分比或内存上限，未宣称所有显卡后端已启用。

## 1.9.2 整集实测

68项自动回归通过。同一29分32秒视频、335条外挂日文字幕，沿用同一DSFlash方案与H.264 CRF16画质，开启全局理解、省用量、自动固定译名和均衡资源，完整导出日文、中文、双语SRT、ASS与MP4。全局分析复用已验证缓存，未重新识别语音。

实测先发现敬称边界与跨条标记问题，再遇到一批无效JSON；补全匹配边界、隔离只读上下文标记、按连续区间分批并启用DeepSeek JSON输出约束后完成。保留失败记录及已通过校验的译文，名称匹配改变的条目重新翻译；没有自动重发失败请求。所有以下累计用量和运行时间均包含两次失败尝试。

- 视频处理累计634.41秒（10分34秒），上一版888.06秒（14分48秒），减少28.6%。最终完成轮587.17秒。调试、重新打包及额外解码校验另计，本次从首次启动到校验结束约23分14秒。
- 翻译累计61.88秒，上一版507.53秒；12线程均衡压制563.89秒，上一版16线程333.80秒。当前主要等待已转移到压制，不能把整体速度改善归因于线程增加。
- API实际累计46次请求、45311 tokens（输入38087、输出7224），包含失败响应。上一版包含分析为195186 tokens，下降76.8%；仅比较翻译用量，下降74.9%。本次分析缓存命中，首次分析的历史用量17372 tokens不算作本次新增请求；推理用量未返回时记录null，不视为零。
- 本集固定表21项，85处名称与称呼、78条字幕；原文登记项无漏匹配、目标名称无缺失，未发现核心人名变体或已登记假名人名残留。
- 翻译质量未判为完全通过：自动表有一项把说明性括注混入译名，影响3条称呼；另有少数不自然表达。名称一致性检查不代表官方译名或完整人工校译。
- 全片音视频完整解码通过；1920×1080原画面加104像素字幕带，成片1920×1184，帧率仍为24000/1001。抽查字幕可读且保留原画面。压制进程实际为Below Normal；一次5秒采样的CPU时间折算约31.6%逻辑处理器、内存约833MiB，仅为短时样本，不是峰值或硬上限。

## 1.9.3 备注修复与编码验证

71项自动回归通过。检查当前生效的1份自动表、21项记录，发现1项“姐姐（称呼）”；说明移入备注，译名恢复为“姐姐”。正常别名括注和人工明确指定的译名不被静默改写，自动候选入口同样清理。旧表留有私有备份。

相同原文、模型和上下文下定向迁移旧缓存，复用335条译文，仅第215、256、306条发生确定的备注清理；时间轴及其余台词保持一致。实测控制器禁止启动所有翻译、分析和识别工作进程，完整导出成功，新增API请求为0。全片85处登记名称／称呼仍匹配，无该备注残留。

保持12线程、低优先级、原分辨率和帧率，高保真从x264 medium/CRF16改为faster/CRF14。室内、街道、运动、细节及暗部5段、合计100秒样本中，SSIM和由平均MSE计算的PSNR均不低于基线；样本总耗时快1.74倍，CPU累计耗时降低约28%，峰值内存从约763MiB降到597MiB，文件约大20%。

同一整集压制从563.89秒降至302.03秒（9分24秒→5分02秒，减少46.4%），成片从1368848974字节增至1657907044字节，增大21.1%。全片原画面区域SSIM为0.995725（旧版0.995443），PSNR为51.292dB（旧版50.886dB）。对比排除有意改变的附加字幕带，全部音视频解码通过。

原片Matroska时间戳以毫秒取整，与MP4精确帧时钟直接比较会错配相邻帧，因此先验证原片42486个带PTS视频包与成片42486帧一致、原片CFR取整误差不超过0.5毫秒，再按24000/1001帧序号统一时间轴。PSNR从全片平均MSE计算，不对逐帧dB简单平均；未经对齐的诊断日志留作本地证据，不作为画质结论。最终全片比对耗时约164秒，另计于导出时间之外。

新版压制一次5秒采样约39%整机逻辑CPU时间、671MiB内存，Below Normal；这是短时观测，不代表硬性百分比上限。上述结果验证本片和所测场景，没有宣称所有片源均达到相同速度或编码无损；其余台词的语言自然度也未因此变成人工校译通过。
